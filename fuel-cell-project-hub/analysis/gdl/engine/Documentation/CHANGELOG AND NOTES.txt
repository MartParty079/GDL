PORTABLE QUICK RUNS
-------------------
The Dashboard now contains five configurable Quick Run slots.

1. Click a Quick Run button to load that slot into the normal settings GUI.
2. Use Rename to choose a readable slot name.
3. Configure ORDER, Processing, Threshold, Sweep, Report, BEAST, and all other pages normally.
4. Press Run. The script asks whether to create/update the selected Quick Run.
5. Choose Yes to save a readable JSON configuration file inside the Quick Runs folder using this format:
   quick run#-(name).json

The Quick Run file stores the complete configured settings object, including duplicate ordered processing steps. It is data-only JSON and can be edited directly in a text editor. Copy it into the Quick Runs folder on another installation and the matching Dashboard slot will load it automatically. Only one saved file should be kept for each slot number; when a slot is resaved, older files for that slot are removed.
