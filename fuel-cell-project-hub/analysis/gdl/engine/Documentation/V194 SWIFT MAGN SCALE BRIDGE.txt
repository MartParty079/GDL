PROFILE SELECTION
-----------------
AUTO:
- Uses the table automatically when it contains exactly one profile.
- With multiple profiles, matches names such as 4X or 10X in the image/folder path.
- Refuses to guess when multiple profiles exist and no path-name match is found.

A specific profile name can be entered instead of AUTO.

PROCESSING ORDER
----------------
Swift .magn scale is applied before:
- crop creation,
- preprocessing,
- threshold sweeps,
- median-radius sweeps,
- particle analysis,
- EPD and area calculations.

FALLBACK ORDER
--------------
1. Swift .magn table
2. Manual direct scale
3. Red-reference-line scale workflow
