START THE PROGRAM
-----------------
Double-click LAUNCH SCRIPT.bat.

The launcher force-closes any existing Fiji/ImageJ instance, waits briefly,
and opens one fresh Fiji instance before running the GDL script. Modern Fiji
launches use --allow-multiple only as isolation protection, so a surviving hidden
instance cannot receive the GDL script through Fiji single-instance handoff.

RUN IN FIJI.py is also provided for manual use from Fiji's script runner. Manual
execution inside an already-running Fiji session cannot close the session that is
currently executing it, so LAUNCH SCRIPT.bat is the recommended start method.

SWIFT IMAGING .MAGN SCALE BRIDGE
--------------------------------
The Set Scale page can read Imaging.magn automatically. Put the table:
- beside the source images,
- in one of the configured parent folders, or
- in the bundled Swift Magnification Tables folder.

Default profile selection is AUTO. AUTO uses the only table profile, or matches
a profile name such as 4X in the image or folder name. The Swift Resolution
number is interpreted as pixels per meter (px/m) and converted to mm/pixel before
cropping, sweeping, or particle analysis.

The included Imaging.magn contains:
- Profile: 4X
- Resolution: 1390466.1089001775 pixels per meter (px/m)
- Pixel size: 0.7191832966 um/pixel


QUICK RUNS
----------
The Dashboard contains five configurable Quick Run slots. Select a slot, rename
it, configure the normal pages, and press Run. Confirm the save prompt to create:

quick run#-(name).json

Quick Run JSON files are saved inside the dedicated Quick Runs folder. v199 serializes every current editable GUI control directly, then also stores the normalized run settings. This includes JMP automatic/fixed histogram binning, EPD bins, Roundness bins, Circularity bins, axis controls, report modes, scale controls, BEAST settings, sweeps, and future standard text/checkbox/dropdown settings. Copy a
Quick Run file into another v199 Quick Runs folder to share the configuration.
Older root-level Quick Run files are moved into this folder automatically.

LARGE PORE REPAIR CARD
----------------------
A new Large Pore Repair sidebar page is included. It is OFF by default. When enabled, it runs after threshold/binary cleanup and before Analyze Particles. The feature requires black fibers and white pores. Review mode marks proposals in red and asks for approval; Automatic conservative mode accepts only candidates that split one large parent pore into exactly two substantial children.
