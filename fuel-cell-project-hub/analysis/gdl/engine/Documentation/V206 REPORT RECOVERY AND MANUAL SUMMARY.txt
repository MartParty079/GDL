REPORT RECOVERY / MANUAL SUMMARY REWORK

5. If zero completed runs are available, a minimal GDL Partial Status Report DOCX is still created.
6. RUN IN FIJI.py has a launcher-level emergency finalizer for uncaught exceptions after an output folder exists.

8. Recovery sources: v206 Report_Recovery snapshots, BEAST worker/agent result pickle slots, ImageJ_JMP_Run_Manifest.csv, BEAST_MODE_Checkpoint.csv, and completed run folders with ImageJ processing notes.
9. Excel summary destination now includes Manual selection at end. Summaries are staged under Word_Report/_Manual_Summary_Staging, then the user selects one or all and copies them into a newly named folder.
10. The manual picker can include summary files already present in a recovered output folder.
