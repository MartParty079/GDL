# Research storage

The native indexing work order supersedes the optional cloud architecture and
RAM-wide catalog described by earlier revisions. Current implementation,
configuration, source boundaries, validation and limitations are documented in
[native indexing](native_indexing.md) and [editable storage](storage_configuration.md).

Historical work orders under reference/ describe earlier requested features;
they are not current application instructions. Removed implementations remain
recoverable in Git history. See the [cleanup manifest](../cleanup_manifest.md).
