# GDL Research Hub Beta 0.4.1

Development prerelease. Stable remains at 0.4.0.

- Independently installable Beta with its own executable, icon, protocol, profile,
  caches, research sandbox and update channel. Both editions can run together.
- Local Beta workspace without production Supabase access or administrator rights.
  Configuration is ready for a separate Beta Supabase project later.
- Update Now with confirmation, cooperative indexing cancellation, safe write
  draining, saved settings/drafts and bounded activity flushing.
- Update on Next Open with per-edition preference, verified downloads and retry
  after download/installer failures, before normal startup work begins.
- Development-only default on develop; automated versioned Beta installers and
  commit-specific protected approval for future production promotion.

Run GDLResearchHubBeta-Setup.exe. It installs alongside Stable and preserves
Stable settings, login state, databases and research files. Copy test data into
the Beta sandbox. Beta never installs Stable releases; Stable never installs Beta.
The installer is unsigned. Microsoft identity testing remains deferred, and no
scientific applications are launched during validation.

GitHub production approval requires the owner to review a release initiated by
another authorized operator because self-review is prohibited. A solo owner
cannot approve their own run; retain the gate until a human explicitly approves
a different review policy. Initial workflow availability on main also requires
an explicitly approved source promotion; development does not update main.
