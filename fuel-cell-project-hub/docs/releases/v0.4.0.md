# GDL Research Hub 0.4.0

Production Windows release of the current research workspace.

- Manual account login, administrator controls and encrypted local sessions.
- Local OneDrive / Files On-Demand research indexing, sample aliases and image families.
- Shared meetings, attendance, notes, action items, transcript imports and research links.
- Measurable weekly contribution reports with PDF and CSV exports.
- Stable release discovery and SHA-256 verified installer downloads.

Download and run **GDLResearchHub-Setup.exe**. The installer upgrades the existing
per-user installation. Source pushes alone do not update installed applications.
The accompanying `.sha256` file verifies the installer download.

Microsoft login remains subject to university administrator approval; use manual
login for now. Microsoft identity testing remains deferred at the user's request.
Automatic recording transcription is not bundled; transcript import and editing
are available. Weekly active-time reporting starts with collected sessions and
does not reconstruct historical active time. The installer is unsigned.

Release validation includes the non-Microsoft regression suite, version history
consistency, source audit and an isolated packaged startup check. Scientific
applications are not launched during these checks.
