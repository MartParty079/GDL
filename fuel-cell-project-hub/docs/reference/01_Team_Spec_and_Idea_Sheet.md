# Fuel Cell Project Hub - Team Spec & Idea Sheet

**Date:** October 6, 2026

## Purpose
The Fuel Cell Project Hub is the team’s single starting point. It connects the tools already used by the capstone instead of replacing them.

## V0.1 win condition
On the project lead’s Windows laptop, open one application and launch all major project software and resources from one place. Multi-user deployment is a stretch goal / V0.2 target.

## Dashboard
- Primary goal + supporting goals
- Current plan / near-term work
- Upcoming meeting agenda from shared Teams/Word document
- Recent major decisions/changes
- Software installed/missing summary
- Main Open Project Repo button + quick links
- Fixed, clean card layout
- No fake progress percentage

## Required software backbone
Swift Imaging, Fiji/ImageJ, JMP, Python tools, Excel, Word, Git/GitHub, Discord, Teams, OneDrive/SharePoint, and SolidWorks where applicable.

## First-launch setup
1. Welcome + **Set up my system**.
2. Auto-scan required software.
3. Show detected/missing.
4. Quick install where safe.
5. Manual links/instructions for licensed tools.
6. Re-scan.
7. **Locate Application** if detection fails.
8. Allow Continue Anyway, but warn every startup until required tools are configured.

## Later modules
- Samples: permanent ID, material/manufacturer/specs/thickness, new/used, current state, experiment history.
- Procedures: versioned templates, structured steps, active/retired lifecycle.
- Experiments: one sample, procedure version, multiple runs, raw data/video/sensor data/pre-post imaging.
- Activity / Requests.
- Bug support.
- Export/handoff package.
